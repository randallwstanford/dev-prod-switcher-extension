## Import Chrome Extension

1. First, ensure you have the extension files (usually in a .crx file or an unpacked folder)
2. Open Chrome and type chrome://extensions in the address bar
3. Enable "Developer mode" by toggling the switch in the top-right corner
4. To install the extension, you have two options:
    - For a packed (.crx) file: Simply drag and drop the .crx file into the Chrome extensions page
    - For an unpacked folder: Click "Load unpacked" and select the folder containing the extension files
